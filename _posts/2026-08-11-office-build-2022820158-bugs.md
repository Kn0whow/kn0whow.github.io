Today I came across a couple of bugs with one of my users on 365 Office apps for Business version 16.0.20228.20158. 

### Excel

First issue was with Excel. As soon as you opened a spreadsheet, or tried to open a new blank workbook, Excel would freeze and crash. However, if you opened it in safe mode it would work.
### Outlook

The issue with outlook was that an error message would pop up when trying to print an email, I did not get a screenshot of this error...

## Troubleshooting

Some of the different troubleshooting steps attempted were:

- Quick repair of office
- Check for updates
- Clear Office cache folder 
- Rename Excel registry key to .old
- Tried disabling all excel add-ins

After checking the event log, I could see an error under event ID 1000, "Faulting module name: mso20win32client.dll".

<img src="{{ site.url }}{{ site.baseurl }}/assets/images/office20158eventerror.png" alt="Event viewer id 1000 excel error">

## Solution

In the end, the solution was to roll office back to the previous version (16.0.20228.20124), by doing the following:

Run CMD as admin, then type the following and press enter

```
cd %ProgramFiles%\Common Files\Microsoft Shared\ClickToRun\
```

Then type and press enter

```
OfficeC2RClient.exe /update user updatetoversion=16.0.20228.20124
```

An Office update box should then pop up and download the relevant version. After the update is done, office apps should then be working as expected.

## Conclusion

I can't see any other mention from Microsoft, or others, that they are having issues with this version as well. But hopefully this will be of help to someone else out there.
